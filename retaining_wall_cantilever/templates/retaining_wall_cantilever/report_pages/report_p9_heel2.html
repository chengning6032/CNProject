9. 牆踵版(Heel)結構設計 (2/7)
9.2 垂直因數化載重詳算 ($W_{u,down}$)

計算每一延米長度內，牆踵版承受之穩定載重（向下）：

1. 版體自重 ($D_c$):

$$ w_{conc} = H_{bp} \times \gamma_c = {{ input_data.H_bp }} \times 0.01 \times {{ input_data.gamma_c }} = \mathbf{ {{ heel_design.w_conc }} } \text{ tf/m}^2 $$

2. 回填土壓重 ($D_s$):

$$ w_{soil} = H_{fill} \times \gamma_{soil} = \mathbf{ {{ heel_design.w_soil }} } \text{ tf/m}^2 $$

3. 地表均佈超載 ($L$):

$$ w_{surcharge} = q \times 1.6 = \mathbf{ {{ heel_design.w_q_u }} } \text{ tf/m}^2 $$
合計下壓分布載重包絡值 ($q_{u,down}$)：
$$ q_{u,down} = 1.2(w_{conc} + w_{soil}) + 1.6w_{surcharge} = \mathbf{ {{ heel_design.qu_down }} } \text{ tf/m}^2 $$
